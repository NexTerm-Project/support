# NexTerm — SSH Terminal for macOS

A fast, native macOS SSH terminal powered by GPU-accelerated Metal rendering.

**Found a bug or have a feature request?** [Open an issue](../../issues/new/choose)

## Features

- **GPU-Accelerated Rendering** — Buttery-smooth terminal output powered by Metal, supporting true color, Unicode, and font ligatures
- **Connection Profiles** — Save SSH connections with host, port, credentials, and jump hosts. Import from `~/.ssh/config`
- **Split Panes & Tabs** — Work on multiple servers side by side with horizontal/vertical splits and tabbed sessions
- **Quick Connect** — Instantly open a connection with a keyboard shortcut (Shift+Cmd+K)
- **Command Snippets** — Save and execute frequently used commands with one click
- **Color Themes** — Choose from 8 built-in themes with real-time preview
- **Secure Authentication** — SSH key, password, and SSH Agent support. Credentials stored in macOS Keychain
- **Broadcast Input** — Send keystrokes to multiple sessions simultaneously (Pro)
- **Session Logging** — Record terminal sessions for auditing and troubleshooting (Pro)
- **Customizable Fonts** — Independent UI and terminal font settings with adjustable size

## System Requirements

- macOS 14.0 (Sonoma) or later
- Apple Silicon or Intel Mac
